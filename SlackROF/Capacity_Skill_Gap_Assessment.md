# SOP 1.1 – Capacity & Skill Gap Assessment

## Overview
This procedure defines how project teams identify recruitment needs by analyzing capacity and skill gaps prior to initiating a recruitment cycle.

---

## Purpose
Ensure all recruitment efforts are based on clearly defined needs, including required roles, skills, and workload gaps.

---

## Intended Audience
- Project Managers / Research Leads  
- HAAG Recruitment Admin Team  

---

## When to Use
- End of each semester  
- Before any recruitment cycle  
- When project scope changes  

---

## Inputs Required
- Current team roster  
- Weekly availability (hours/week)  
- Project roadmap / deliverables  
- Existing team skill coverage  

---

## Procedure

### 1. Assess Current Team Capacity
- List all active team members  
- Document weekly availability  
- Identify current responsibilities  

---

### 2. Identify Project Demands
- Break deliverables into tasks  
- Estimate hours required per task  
- Map tasks across timeline  

---

### 3. Perform Gap Analysis
- Compare total capacity vs required workload  
- Identify:
  - Capacity gaps (hours shortage)  
  - Skill gaps (missing competencies)  

---

### 4. Define Required Roles
For each gap, document:
- Role title  
- Required skills  
- Preferred experience  
- Weekly commitment  
- Expected deliverables  

---

### 5. Publish Role Description
- Compile into standardized role description  
- Post in:
  - `#project-recruitment` Slack channel  
  - HAAG centralized recruitment hub  

---

## Output
- Standardized Role Description Document  

---

## Success Criteria
- Roles are clearly defined  
- No ambiguity in expectations  
- Recruitment needs align with project goals  

---

## Enforcement
- Recruitment cannot begin without completing this SOP  
- HAAG Admin must verify role descriptions before posting
