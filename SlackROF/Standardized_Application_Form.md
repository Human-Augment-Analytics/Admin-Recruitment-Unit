# SOP 2.1 – Standardized Application Form

## Overview
This procedure standardizes how applicant data is collected to ensure consistent and fair evaluation across all candidates.

---

## Purpose
Create a structured, repeatable application process that improves candidate comparison and evaluation efficiency.

---

## Intended Audience
- HAAG Recruitment Admin Team  
- Project Managers  

---

## When to Use
- During every recruitment cycle  

---

## Tools Required
- Slack Workflow Builder  

---

## Procedure

### 1. Create Application Form
Include the following required fields:

- Name  
- Academic Year / Major  
- Relevant Coursework  
- Technical Skills  
- Prior Experience  
- Weekly Availability  
- Resume (link/upload)  
- Motivation Statement  

---

### 2. Configure Submission Workflow
- Route submissions to:
  - `#project-recruitment-review` (private channel)  
- Restrict visibility to admins/reviewers  

---

### 3. Publish Application
Post form in:
- `#project-recruitment` channel  
- HAAG-wide announcements  

Include:
- Role descriptions  
- Application deadline  

---

### 4. Organize Submissions
- Store submissions consistently  
- Tag or categorize applicants (optional)  

---

### 5. Conduct Structured Review
Evaluate candidates based on:
- Skill match  
- Availability  
- Experience relevance  
- Motivation  

---

## Output
- Structured applicant dataset  

---

## Success Criteria
- All applicants provide consistent information  
- Admins can efficiently compare candidates  

---

## Enforcement
- Only applications submitted via the form are accepted  
- No informal (DM/email) applications allowed  

---
